# SOKET EŞLEŞTİRME FELAKETİ

## DÜNYANIN EN CİDDİ VE EN ABSÜRT ÇORAP SİMÜLATÖRÜ

Bu repository, insanlığın en büyük varoluşsal sorununa çözüm bulmak için yaratıldı: **Çoraplar neden asla eşleşmez?**

### Nasıl Çalışır?

```bash
python corap_devrimi.py
```

Program çalışır. Çoraplar eşleşmez. Sen de eşleşemezsin. Her şey planlandığı gibi.

### Özellikler

- %100 gerçek çorap isyanı simülasyonu
- Felsefi monologlar (rastgele)
- Sonsuz eşleştirme başarısızlığı
- Kayyum onaylı kod

### Uyarı

Bu programı çalıştırmak çoraplarınızın isyan etmesine neden olabilir. Sorumluluk kabul etmiyoruz.
